# M1racle Intaglio Director v1.3.2 | 梯田色彩与区域控制回归

## 目标

v1.3.1 已提及天空和雾气保护，但上一轮五张探索样图仍出现颜色漂移、远景纹理外溢、T02/T03 混同和 T04 全局点幕。v1.3.2 针对这些缺陷增加源图配色硬锁、区域映射和技法区域规则，并提供可重复的评分计算器。

## 固定测试场景

源图为用户在本次对话提供的彩色梯田照片。画面可见左侧多级稻田与田埂、左中小型人物、右中木屋、远处青绿色山体及雾气。该源图不加入公开仓库，生成结果也不加入公开仓库。

五次测试均须以同一源图作为内容输入，分别只改变 T01、T02、T03、T04、T05。使用严格保真、原始比例、原图颜色继承；不得强制 16:9，不得新增画框或文字，不得改变物体数量和位置。每张图独立检查，不得用一张图代替其他技法的证据。

## 本版改动

1. 移除可能诱导照片变成奶油纸色的 paper tone 表述。
2. 为彩色源图添加逐区域色相、饱和度、明度、白平衡和综合色调硬锁。
3. 加入通用区域化纹理规则和梯田专用区域图，约束田埂、植被、木屋、人物、远山、天空与雾气。
4. 为五种技法增加区域执行约束，重点控制 T02 交叉蚀线、T03 局部毛刺、T04 点密度和 T05 局部绒黑。
5. 新增 100 分制视觉评分卡。评分必须由人工观察填写证据；脚本只计算权重与硬门槛，不分析图片。

## 评分方法

每项按 0–5 分，乘以对应权重。总分 100。85 分及以上且硬门槛全部通过为 PASS；75–84.9 为 CONDITIONAL；低于 75 或任一硬门槛失败为 REJECTED。缺少证据或缺少硬失败标记时为 UNVERIFIED。

硬门槛包括：几何与构图至少 4/5，原图配色至少 4/5，主体完整性至少 4/5，技法真实性至少 3/5，区域控制至少 3/5，画面洁净度至少 4/5。未经授权加框、增删主体、严重改变构图/裁切、擅自换色或严重全局纹理外溢，直接 REJECTED。

## 验收限制

GitHub CI 只验证提示词构建逻辑、评分脚本、版本和文件完整性。它不执行图像模型，也不为真实图像打分。真实五图测试必须在发布后执行，评分依据是实际生成图与源图的逐项视觉比对。本文件不预填任何 PASS 或虚构分数。
