# M1racle Intaglio Director v1.3.1 | 梯田视觉场景补丁

## 版本目标

改进 2026-11-09 梯田同图探索性生成中暴露的全局纹理外溢、未经授权的装饰画框与技法混同；保持 T/I/P 三层体系、原图配色继承和运行时能力门禁。

## 输入与人工观察

用户提供的横幅照片包含左侧层叠梯田、左中小型行人、右中木屋，以及远方青绿色山体和雾气。此前已生成五种技法的探索性作品，T01 与 T04 的线条和点纹特征清晰，但 T02 与 T03 仍然相似，T05 接近柔焦绘画。部分作品给天空和雾层铺满均匀印痕，另有作品新增画框。

## 代码修改

1. 对全部重绘与精修提示词添加低细节区域保护：天空、雾气、远山与高光不被均匀排线、点阵、磨砂噪点或数字柔焦覆盖。
2. 明确禁止未授权的画框、印版边、旧纸污渍、签名和新增物体；继续锁定梯田地形、人物、木屋、比例与空间位置。
3. 强化 T01 雾天空线条保护、T02 局部交叉蚀线、T03 刻痕边缘的局部毛刺、T04 雾天空点纹密度与 T05 反数码模糊要求。
4. 增加回归测试，覆盖五种技法的中英文场景保护文本、颜色继承和技法差异。

## 验收边界

Python 回归测试、完整性清单及 GitHub CI 检查的是程序、文本规则和发布文件的完整性，无法替代真实图像模型的质量检查。

**v1.3.1 真正固定源图的五技法成图基准、身份与几何保真量化、盲评和 24 场景作品计划仍为 UNVERIFIED。** 本版只宣称修正提示词约束和程序测试，并不宣称五技法图像成功率达到任何百分比。用户原图及生成图没有自动提交到公开仓库。
