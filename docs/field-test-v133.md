## 本版工程修复

旧版 visual_scorecard.py 对任何填写完整的分数表均可计算 PASS，缺少对真实原图和输出字节的强制绑定。新版本要求 --source、--output、文件摘要、非空 run_id、technique、model_or_tool、output_kind、完整人工观察证据和全套布尔硬失败项。仅有自填分数不再可通过。

图像校验只依赖标准库读取 PNG/JPEG 宽高和 SHA-256；原始宽高比相对变化超过 1% 强制拒绝，但它不具备辨认海报、图片对象或真实刻线的能力。这些项目必须由真实视觉审核完成。

发布流程还修正了旧版发行说明重复引用 v1.3.1 的问题；改用版本化发行说明、可复现 ZIP 打包及发布后完整附件摘要核验。
