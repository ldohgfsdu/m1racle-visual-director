# 雕刻主技法（五大互斥主导机制） / Technique families

原则：一次成图仅选一种 **主导调子机制**。小面积辅助刻线允许，但不能把五种机制平均混合。以下是图像模型的表现指令，不声称物理制版工艺或真实印刷分版。

| ID | 技法 | 主导图像构造 | 主要排除项 |
| --- | --- | --- | --- |
| T01 | 精密刀刻 / 钢凹版视觉 / Precision burin engraving | 以端点收细、宽窄受控的刀刻线为主要造型手段；线段长短、转向与疏密服从局部表面，不把所有区域铺成长排线。 明暗由线距、刻线粗细、成束方向与留白转换；交叉线仅点到为止，保持轮廓干净。 | 不要把点阵、模糊毛边或大面积连续黑调子作为主表现。 |
| T02 | 铜版蚀刻 / Copperplate etching | 由笔触感明确、轻微不等距的蚀刻线组织形体；转折、材质和受力决定刻线组方向。 用交叉排线的层数、角度变化和局部断线建调子；在关键结构保留开放纸白。 | 不要以无方向的均匀点刻或平滑暗调代替蚀刻线。 |
| T03 | 干刻柔边 / Drypoint with ink burr | 以有压强轻重差异的短中程划痕刻线为主体，线缘带轻微储墨毛刺和绒感。 通过断续线簇与柔绒深浅构建体积，最深处仍见局部刻痕方向；高光由未着墨纸面打开。 | 不要工业式等距排线、规则点阵或整图磨砂噪点。 |
| T04 | 点刻雕版 / Stipple engraving | 以彼此分离的、疏密与大小受控的雕刻墨点作为主体调子；轮廓只允许极少量清晰辅助线。 明暗主要靠局部点密与点径阶梯塑形，沿形体变化而非随机散点；纸白亮区点量极少。 | 禁止连续平行排线、明显交叉排线、连续黑色喷绘渐变作为主要阴影方式。 |
| T05 | 美柔汀调子版 / Mezzotint tonal engraving | 以极细密摇刀颗粒形成的均匀深墨基调为主体，明亮区域通过刮削与磨光从暗底中显现。 用连续但具有版画颗粒感的黑—灰—纸白明度塑造体积，而不是用长排线覆盖照片。 | 不得把大量交叉排线、点阵筛网或喷枪渐变伪装为美柔汀。 |

## 选择逻辑

- 先依据用户指定技法；未指定时根据预设 I01–I08 的 `technique_id` 映射；完全不指定且新生成/重绘时默认 T01。
- 既有版画精修且没有要求更换风格时：`INHERIT`，延续内容源已有的刻线/调子，不擅自切换技法。
- 点刻与美柔汀是 **与排线不同的主导机制**：母风格不得要求所有输出必须由连续排线建调子。
- 同一画面有不同材质时只调整该技法内部的点密、线簇、层次或明度，不能不经用户允许把主技法切换成另一类。
- 样张是 1.1/1.2 的历史视觉参考，不足以作为新技法分类的实验验证。
