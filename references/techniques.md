# 雕刻主技法（五大互斥主导机制） / Technique families

原则：一次成图仅选一种 **主导调子机制**。小面积辅助刻线允许，但不能把五种机制平均混合。以下是图像模型的表现指令，不声称物理制版工艺或真实印刷分版。

| ID | 技法 | 主导图像构造 | 主要排除项 |
| --- | --- | --- | --- |
| T01 | 精密刀刻 / 钢凹版视觉 / Precision burin engraving | 以端点收细、宽窄受控的刀刻长线为主要结构；线群沿对象曲率与透视有规律地展开。 明暗由线距、刻线粗细、成束方向与留白转换；交叉线仅点到为止，保持轮廓干净。 | 禁止将整片天空、雾气铺满同向刻线；不要把点阵、模糊毛边或大面积连续黑调子作为主表现。 |
| T02 | 铜版蚀刻 / Copperplate etching | 由笔触感明确、轻微不等距的蚀刻线组织形体；转折、材质和受力决定刻线组方向。 用交叉排线的层数、角度变化和局部断线建调子，交叉只集中于实际需要的暗部；雾、天空及关键高光保留开放纸白。 | 不要以无方向的均匀点刻或平滑暗调代替蚀刻线。 |
| T03 | 干刻柔边 / Drypoint with ink burr | 以有压强轻重差异的短中程划痕刻线为主体，线缘带轻微储墨毛刺和绒感。 通过断续线簇与沿刻痕边缘出现的局部储墨毛刺构建体积；即使深影仍见刻痕方向，明部打开纸白，不得让全图同样柔糊。 | 不要工业式等距排线、规则点阵或整图磨砂噪点。 |
| T04 | 点刻雕版 / Stipple engraving | 以彼此分离的、疏密与大小受控的雕刻墨点作为主体调子；轮廓只允许极少量清晰辅助线。 明暗主要靠局部点密与点径阶梯塑形，沿形体变化而非随机散点；纸白亮区点量极少。 | 禁止连续平行排线、明显交叉排线、连续喷绘渐变或在天空与雾气中无差别铺满点阵作为主要阴影。 |
| T05 | 美柔汀调子版 / Mezzotint tonal engraving | 以极细密摇刀颗粒形成的均匀深墨基调为主体，明亮区域通过刮削与磨光从暗底中显现。 用连续但具有版画颗粒感的黑—灰—纸白明度塑造体积，而不是用长排线覆盖照片。 | 不得把大量交叉排线、点阵筛网、全局柔焦、数码高斯模糊或简单压暗照片伪装为美柔汀；需要真实可辨的局部绒黑调子与刮亮关系。 |

## 选择逻辑

- 先依据用户指定技法；未指定时根据预设 I01–I08 的 `technique_id` 映射；完全不指定且新生成/重绘时默认 T01。
- 既有版画精修且没有要求更换风格时：`INHERIT`，延续内容源已有的刻线/调子，不擅自切换技法。
- 点刻与美柔汀是 **与排线不同的主导机制**：母风格不得要求所有输出必须由连续排线建调子。
- 同一画面有不同材质时只调整该技法内部的点密、线簇、层次或明度，不能不经用户允许把主技法切换成另一类。
- 样张是 1.1/1.2 的历史视觉参考，不足以作为新技法分类的实验验证。

## v1.3.1 场景分区保护

本版根据梯田、木屋、人物和远山雾气的同图探索性成图问题，强化背景保护与技法边界。天空、雾气和远山必须先判断实际细节和透视，再决定是否留下纸白或极稀疏印痕；禁止把局部物体的刻线扩散成全图叠纹。T02 的交叉线只用于实际阴影，T03 必须能看见沿独立划痕分布的局部储墨毛刺，T05 不允许用数字柔焦冒充摇刀与刮亮。图像编辑不得擅自新增画框、旧纸边或裁切原图。

以上属于生产约束和回归测试要求，真实固定源图的五技法视觉验收尚未通过。

## v1.3.2 区域化技法执行

每种技法必须在源图的材质区域内部形成主导痕迹，不能将纹理作为全局滤镜覆盖画面。区域策略只作用于原图实际存在的区域，不得因为文字示例而生成新物体。

- **T01**：长线只沿田埂曲率、坡面和建筑结构展开；远山线宽与密度递减；天空、雾气和高光不铺满长线。
- **T02**：交叉蚀线仅用于田埂背光面、木屋阴影和确有需要的植被暗部；远山使用稀疏短线，天空与雾气保留开放层次。
- **T03**：短刻痕与储墨毛刺局限于田埂土壁、木材和植被边缘；毛刺必须贴附具体划痕，天空、雾气和远景不加全局磨砂。
- **T04**：点密度随局部明暗变化；植被与土壁可较密，远山稀疏，天空和雾气仅极少点或无点，禁止均匀点幕。
- **T05**：绒黑只落在田埂背光面、木屋阴影和植被暗部；亮部以局部刮亮显现，远山随距离降低对比，天空与雾气保留原色和明度。
