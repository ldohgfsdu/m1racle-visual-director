# 结果验收 / Output checks

逐项记录与可执行门禁见 [成图验收与真实作品基准](output_review.md)，八套历史配方的验收特征见 [style_acceptance.json](style_acceptance.json)。内容硬门槛优先于风格评价；所有 PASS 必须有实际观察与区域依据，文件摘要必须对应本轮真实输出。

先通过 [runtime_policy.md](runtime_policy.md) 的工具能力门禁，再读回真实生成结果，再对照用户请求及内容原图逐项记录 PASS / ISSUE / UNVERIFIED。没有读取结果、原图缺失或细节分辨率不足时，不得给对应项目 PASS。

| 项目 | 检查方法 | 修复边界 |
| --- | --- | --- |
| 主体保真 | 并排比较数量、身份、轮廓、姿态、视点、位置和识别性细节 | 仅修失真区域，不重新设计整幅图 |
| 刻线构形 | 放大到原生 100% 检查轮廓、曲面、亮暗是否由方向与疏密变化的线构成 | 去除摄影底图残留和统一网纹 |
| 配色一致 | 对照已解析的最终色系；检查预设颜色是否泄漏 | 只修配色，不增加场景元素 |
| 内容隔离 | 对照主题与每张图的角色，检查样图物体或布局是否混入 | 删除未经要求的元素并恢复原构图 |
| 背景克制 | 检查装饰是否符合 none / auto / guilloche 策略，是否侵入主体 | 只调整指定背景纹，不删必要背景内容 |
| 多尺度可读 | 查看原图、约 25% 缩略图和手机宽度；关注焦点与摩尔纹 | 局部降低线密和峰值对比，不整体模糊 |
| 比例与透明 | 检查实际输出比例、裁切、原透明背景是否保留 | 不根据提示词推断输出参数已生效 |
| 交付真实性 | 只报告实际工具调用、真实传入的图与读取结果 | 无法确认则 UNVERIFIED |

修复模板：只修复 [具体问题与区域]。保留 [本轮不变项]。沿已有形体重建需要的刻线，最终配色为 [已解析色系]，背景采用 [已解析策略]，不增删未授权物体。

通常最多两轮针对性修复。仍有问题时如实保留 ISSUE；不能为了宣称通过反复更改任务、降低要求或重新抽样挑图。若工具不支持局部编辑，说明全图重绘可能漂移，选择最小可行修改。

自动化测试只能证明提示词和命令行为；真实出图样本只能支持被执行的具体场景。不能把测试数、一次满意结果或主观相似度包装为普遍成功率。

可复用的真实出图任务见 `tests/visual_cases.json`。只有真实执行并检查了该任务，才将其记录为已验证；原始参考图不算本 Skill 的生成成果。

## 1.2.0 防伪阳性判据（尤其针对桥、玻璃楼、水面）

- **先排除降级产物**：若只是像素滤镜、结构张量流场、逐像素排线或叠网，不能标记“已完成图像模型式重绘”；必须注明“程序化近似”。
- **防纹理外溢**：若原图桥底横梁原有水平线，但楼群、桥塔、船身也被大面积同向水平条纹填充，应标记 `FAIL: 形体刻线`；即使物体轮廓尚可辨，也不能给该项 PASS。
- **独立验证色版**：宣称“三个油墨版”需要提供可检查的分色蒙版或分色证据；仅对 RGB 输出调色不等于真实可分版套印。
- **显著缺陷优先**：水面过黑、主体边缘丢失、大面积线条摩尔纹、船体被压暗、桥塔形体扭曲都应显式报告 ISSUE，不得以“密度极限”掩盖目标未达成。
- **停止准则**：每轮必须说明相比上一版具体改善了什么；两轮无明确可观察改善就不再调参。

## v1.3 五技法鉴别（新增）

- T01：主要明暗确实由收细刀刻线的线距/线宽承担；机器刻线网屏化则 ISSUE。
- T02：自然转向的蚀线及局部交叉排线形成体积；整幅同一方向则 ISSUE。
- T03：柔毛刺只贴合划痕边缘，而非整图噪点；否则 ISSUE。
- T04：主要明暗由雕刻点的密度/大小塑形，而不是传统平行排线；否则 `TECHNIQUE_COLLAPSE`。
- T05：主要表现为绒黑调子底与刮光高光，不依赖十字排线；否则 `TECHNIQUE_COLLAPSE`。
- **不得凭五段不同的文字模板判定成图差异通过**；需要实测同图、同色、同构图，盲评时能够解释痕迹差异。
- 当指定 `--technique Txx` 与配方 Ixx 的默认映射不一致，视为主技法优先，忽略不兼容的配方节奏；不能为保留预设而混合矛盾机制。
