# 模型与参考图选择规则

本 Skill 是**固定钢版雕刻风格**，不是风格推荐器；是否使用参考图只决定保真策略，不改变画风。

## 来源角色优先级

1. 用户上传并要求修改的图片是**内容源/编辑底图**。需要真实传入支持图像编辑的工具，禁止用示例图代替。
2. 用户上传的纯画风图是**风格源**；用户新主题决定实际画面，不复制风格源的主体、人物、地标或构图。
3. 仓库 `gallery/samples/*.svg` 仅为**配色/线条结构示意**，未经模型适配测试，不得默认为可用的图片输入。
4. 没有经过验收的风格参考图时，使用 `references/banknote-engraving.md` 和 `references/prompt-patterns.md` 的文字风格契约，不得捏造本地图片路径。

## 决策

- T2I：默认文字生图，无须使用参考图。若模型经真实测试证明细密排线难以稳定生成，且存在经核验的样图、工具支持图像输入，可在**不复制样图内容**的提示下传入风格参考。
- REF-CREATE：如果用户提供纯风格参考，只提取画风表现。目标风格仍锁定本 Skill 的雕刻家族。
- TRANSFORM / LOCAL-EDIT：优先传入用户底图并遵守保留区域；不支持图片输入/遮罩则诚实说明，不能声称已完成改图。
- COMPOSITE：逐张指定图片职责（主体、背景、结构、风格），不要全部混成同一份图片。
- 不得凭模型名称、版本或宣传材料臆测“原生支持”特定画风；模型能力需由实际测试数据证明。

## 何时考虑向模型传入风格参考图？

只有同时满足**真实文件存在、图片格式被该工具接受、参考用途明确、经过最小生成测试**四项，才可以把它标为可复用的风格参考。未知模型仅按“未标定”处理，不声称百分之百风格忠实。

能力记录见 [model_capabilities.json](model_capabilities.json)。目前没有已标定的模型，也没有经出图验收的模型参考图片。先做文字生图是诚实而安全的基线。
