# 8 套历史视觉配方 / Legacy visual recipes

八个 Ixx **不再被描述为八种雕刻技法**；每个配方映射一种主导技法，另外提供线节奏与构图权重。默认配色 Pxx 可覆盖，但与技法分离。所有题材名称仅为参考图索引，不授权添加场景物体。

| 配方 | 名称 | 主导技法 | 默认色板 | 技法内部的差异 |
| --- | --- | --- | --- | --- |
| I01 | 蓝色海滨刻版 | T01 | P01 | 突出直线结构的精密闭合、透视收束和大面积纸白，减少局部交织以获得通透感。 |
| I02 | 赭粉纪念碑幻想 | T02 | P02 | 以层叠交叉蚀刻线压低大体块中调，强调尺度与光照对比，不放大或添加任何建筑。 |
| I03 | 炭黑史诗叙事 | T05 | P03 | 用有选择的暗底、被刮出的轮廓光以及厚重但不堵死的投影形成戏剧节奏。 |
| I04 | 古典山城地志 | T02 | P04 | 沿主要起伏的表面将蚀刻线组织成疏密变化的曲折线群，空间远处细节优先弱化。 |
| I05 | 雕刻人物肖像 | T04 | P05 | 利用微小点簇保留细腻转折和可辨识的局部特征，轮廓不硬化、不过度修饰。 |
| I06 | 青蓝全景银行刻版 | T01 | P06 | 以较长的连续刀刻线带组织大片表面，远近通过线距与对比控制，避免横纹整图贯穿。 |
| I07 | 靛蓝樱粉套印 | T03 | P07 | 细短柔边刻线和较疏的留白交替，弱化次要区域；保持空白与线簇对比。 |
| I08 | 档案港口志书 | T02 | P08 | 依靠分段线组、局部交叉排线和明确留白表达复杂层次，保持档案插画的可检索清晰度。 |

特别说明：I01/I06 都是 T01；I02/I04/I08 都是 T02。它们的**技法机制相同**，区别仅是配方，不把它们的差异伪装成五种以上的独立工艺。

## 配色库独立于配方

| ID | 色板 | 描述 |
| --- | --- | --- |
| P00 | 中性石墨 | 深石墨墨色与自然纸白。 |
| P01 | 海蓝赤陶 | 深海蓝主墨，暖纸白，少量赤陶色辅墨。 |
| P02 | 藏青铜粉 | 深藏青主墨，暖铜粉辅墨，旧纸灰。 |
| P03 | 炭墨冷灰 | 炭墨黑与冷灰，纸白；不默认添加火色。 |
| P04 | 石墨灰绿 | 石墨主墨，低饱和灰绿辅墨，暖纸白。 |
| P05 | 黑墨象牙 | 深石墨或黑墨与温暖象牙纸白。 |
| P06 | 普蓝钴青 | 普鲁士蓝主墨，钴青辅墨，纸白。 |
| P07 | 靛蓝樱粉 | 靛蓝主墨与柔和樱粉辅墨，象牙纸白。 |
| P08 | 炭灰档案蓝 | 炭灰主墨，低饱和灰蓝辅墨，旧纸灰白。 |

配色优先级：用户直接指定 `--palette` > 主题中有明确用色要求 > 编辑继承原图（除非 `--palette-id` 显式换色）> `--palette-id` > 新生成时配方默认 Pxx 或 P00。

用户指定单色/禁用色时，生产提示词只输出最终合法颜色，不能把预设名中带颜色的字放进生产提示词。参考图片只提供用户允许的视觉属性。
