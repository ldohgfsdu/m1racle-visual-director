# 自动风格识别与选择：视觉指纹法

适用时机：用户提供风格参考图；或用户未指定画风，Agent 要判断适合当前题材的视觉语言。不要将视觉风格识别等同于识别“这是什么场景”。

## A. 从参考图读取视觉指纹

逐张检查并记录以下字段；只能依据实际可见画面，不猜拍摄设备、作者、真实工艺或版权来源：

```yaml
medium: 摄影 / 钢版雕刻 / 木刻 / 毛笔 / 工笔 / 水彩 / 渲染 / 矢量 ...
shape_language: 有机/几何、精细/概括、线主导/面主导
mark_making: 刻线密度、笔触方向、交叉排线、渐变、点描、版印网纹等
palette: 主色、辅色、背景色、饱和度、冷暖及颜色数量
value_and_light: 高对比/低对比、阴影构成机制、光方向、明暗层次
composition: 焦点位置、前后景层次、视觉重心、视角、留白
surface: 纸张、画布、金属、颗粒、油墨、反射、边缘质量
identity_cues: 区分这种风格与普通风格的 3–6 个可观察特征
not_style: 具体地标、角色、偶然道具、无关背景文字等
```

**提炼顺序**：观察 → 提炼可验证的视觉规律 → 区分主题与画风 → 生成绘制技术句。不要直接堆叠“复古、史诗、高清”等低信息密度词。

## B. 多参考图归纳

- **共同特征**：如果不同参考都具有细密排线、象牙白纸、双色油墨，可以作为风格共识；只要一张图出现了帆船，就不能推断“所有图都需要帆船”。
- **互相冲突**：若一组既有蓝色纸币钢版，也有黑白古典雕版，应保留共同底层“精细刻线 / 排线塑形”，同时把“双色油墨+显著 Guilloché”与“单色高对比”作为**两种分支**，按用户意图选其中一种。
- **主体与画风分离**：参考图是富士山不代表新图也必须富士山；参考的形体结构不代表所有地域/文化特征应复制。
- **强约束显式分工优先**：用户说“图1色彩、图2构图、图3主体”时按这个分工执行，不能根据图片外观自行重新分配。

## C. 没有参考图：目的驱动选择

1. 要传递**事实形态** → 写实照片、棚拍、精确图示，优先准确与可读。
2. 要传递**情感叙事** → 电影摄影、编辑插画、古典雕刻等，由情绪强弱、时代感、渠道来选。
3. 要传递**文化或历史质感** → 提炼具体工艺：工笔、木刻、铜版、丝网版等，不把国别当风格。
4. 要传递**品牌识别** → 已有形象和 Logo 一致性优先；别为“更美”发明新 Logo。
5. 要传递**复杂空间** → 构图明确的等轴测、建筑可视化、概念设计；需要精确尺寸时使用专业设计工具而非猜测绘制。

完成后参照 SKILL.md 的 14 分评分法。候选只需 2–3 个：选主风格，最多一个真正必要的次风格。

## D. 文本到具体画风示例

- “一本古代航海故事封面，很古老又精致” → 可候选 `steel-engraving-mono`（历史版画）与 `banknote-intaglio`（精密纪念风），若要求彩色与复杂防伪线则后者更优。
- “给电子秤做商品详情展示” → `photo-studio-product` 优先；纸币风不能准确展示电子秤材质/刻度。
- “给古典小说中的谋士画插页” → `steel-engraving-mono` / `editorial-ink` 依据黑白印刷和篇幅选择。
- “有点 Apple 风的极简写作产品页面截图” → 用户意图可能是 UI 设计而非位图艺术；先识别交付物，不能用造一张概念图片替代可编辑产品设计。

## E. 防止失败的原则

- **技术属性比抽象形容词更有效**：`shadows formed by contour-following cross-hatching` 好于 `vintage detailed`。
- **单图内优先一个主风格**：除用户明确要求拼贴或混合媒介外，不把水墨、油画、赛博朋克、写实、纸币雕刻全部堆在一个提示词。
- **不能虚报量化色值/时代**：若图片未经像素抽样/可靠判断，不凭空说“完全是 #123456”或“确系1890年代”。
- **风格不等于内容**：保持字体、人物、实体、品牌约束是独立任务。
