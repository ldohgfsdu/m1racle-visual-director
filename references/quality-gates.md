# 输出质检协议（真实检查，不伪报）

## 1. 基础检查

如果确实已生成可见图片，按用户指定的可观察维度检查：

- **完整性**：指定主体、物体、姿态、数量、背景是否出现；比例是否正确。
- **风格**：是否体现于描画机制，而不是只叠加颜色/纸纹。若用户给参考图，对比参考的线条、色彩、质感等明确维度。
- **结构**：透视、连接、脸、手、手指、腿、古建筑梁柱、帆船构造等是否有显著异常。
- **空间**：前景/中景/背景不粘连；焦点突出；主体不被装饰覆盖。
- **文字**：要求出现的文字是否拼写正确、清晰、无缺漏；不需要文字时是否出现伪字符。
- **保真**：编辑模式下是否出现背景漂移、主体换脸/变形、其他区域误改。
- **交付**：文件确实存在或图像工具确实返回成功；不可用或失败时不得给假链接。

## 2. 各路由额外质量门槛

| 路线 | 验证重点 | 典型失败 |
|---|---|---|
| T2I | 主题与风格适配、主体可读性 | 为炫技牺牲核心内容 |
| REF-CREATE | 继承被指定维度，但主题确实全新 | 不该继承的场景或人物被原样带入 |
| TRANSFORM | 相同内容、身份、姿态与大构图 | 主体替换、建筑增删、机位大变 |
| LOCAL-EDIT | 编辑范围严格，周围光影衔接合理 | 改背景导致人脸变形，局部改动扩散 |
| COMPOSITE | 来源分工、接触阴影、尺度、视线统一 | 照片拼贴感、重复人物、光源冲突 |

## 3. 银行券雕刻专用质量门槛

- 可看出**有方向的纤细刻线**，阴影来自线条密度。
- 山体/水流/衣褶/建筑具有与其形体一致的刻线方向。
- 天空的 Guilloché 曲线不是简单方格覆盖，也不是杂乱线团。
- 主体没有被等强度纹样淹没，宏观可读。
- 2–3 色油墨关系连贯，不能退化成普通彩色插画+泛黄滤镜。

## 4. 失败时怎么办

先定位**最重要的 1–2 个失败原因**，只针对问题修订：

1. 漏主体 → 在提示词开头加强主体、重要数量和相对位置。
2. 编辑范围扩散 → 重申锁定区，若工具支持使用蒙版/区域编辑。
3. 风格偏离 → 增加对应风格中**制作技术可观察的机制**，减少形容词。
4. 图像结构错误 → 简化拥挤构图，提高主体尺度并强调透视与结构。
5. 文字错 → 优先在支持排字的编辑流程完成文字，而不是声称模型文本已准确。

不做无目的重复抽卡。工具未开放重新编辑或预算不允许时，如实说明仍有哪些未验证/未达成之处。

## 5. 状态用语

- `GENERATED_AND_REVIEWED`：有实际成图且已检查。
- `GENERATED_UNVERIFIED`：有实际成图但不能有效检查。
- `PROMPT_ONLY`：只写了提示词，没有生图。
- `BLOCKED_TOOL`：缺少需要的生成/图像输入能力。

**不能**因通过元数据或脚本检查就写出图像“质量已通过”。
