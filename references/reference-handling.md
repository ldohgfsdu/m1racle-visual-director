# 图像来源角色与保真

本 Skill **风格已经固定**，原图只影响“哪些内容要保留”，不再决定是否切换水墨/摄影/3D。

| 用户要求 | 操作 | 保留与修改 |
|---|---|---|
| “参考这个画风，画另一座城” | `REF-CREATE` | 只提取雕刻纹路/配色/纸纹；不要复制旧城 |
| “把这张照片转成纸币雕刻” | `TRANSFORM` | 原有主体、视角、建筑布局不变 |
| “保留这个人的样貌” | `TRANSFORM` 或 `COMPOSITE` | 尽量保留辨识特征与动作 |
| “只修改图中一个物体” | `LOCAL-EDIT` | 未授权区域尽量不改变；不默认全图转换 |
| “图1人物，图2背景” | `COMPOSITE` | 明确各图职责，不混入其他图主体 |

保真层级：`L0` 纯文生图，`L1` 只参考风格/构图，`L2` 保留主体改画风，`L3` 精准局部修改。

工具无图像输入能力时不能谎称已经看图改绘。用户给多张图片时逐张确认 role，不用文字描述冒充真实图像输入。
