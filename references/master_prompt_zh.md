# Intaglio Director v1.3｜中文通用母提示词

**用途：** 由执行环境中的 Agent 先解析用户要求并选择一个 T 技法，最终交给**有图像生成/改图能力**的模型。这个模板不是图片，也不是请 Python 写渲染器。

【任务填写】
主题：[主体及用户明确禁止、保留内容]
操作：[generate 新生成 / redraw 改绘上传的内容源 / refine 精修]
图片角色：[逐张说明哪张是内容源、哪张只提供技法、哪张只提供颜色]
不变项：[主体身份、数量、姿态、形状、视点、位置、构图、比例、透明度；仅锁定未允许改变的项]
主技法：[从 T01 精密刀刻、T02 铜版蚀刻、T03 干刻、T04 点刻、T05 美柔汀中只选 **一项**；无换技法要求的精修使用 INHERIT]
配方：[可选 I01–I08；与主技法不一致时跳过配方节奏]
最终配色：[用户明确色 > 编辑原色 > 显式选 P00–P08 > 新生成默认色]
背景：[none / auto / guilloche；编辑默认维持背景]
比例：[编辑继承内容源，新生成按任务]

【生产指令：只保留已经选定的分支】
以内容源（如果有）为所有主体、数量、场景结构、透视和构图的事实依据；风格参考仅提供允许的技法纹理，不得借用其物体、故事或文字。改变的是印痕表现，**不要在摄影像素上叠加统一刻线滤镜**。

按照 `techniques.json` 中已选 T 家族的「主导痕迹、调子建模、边缘与排除项」完整构建图像；禁止同时强制所有五种技法，也不允许同一技法自动变成平均混合排线。只有与 T 映射相同的配方 Ixx 才附加其独立节奏描述。必须把局部原有条纹（建筑格栅、桥面梁格、水波）区分于雕版线条，不允许延伸到其他物体。保持主体 25% 缩图可读、100% 放大印痕可辨。

最终只执行一个可检查的色板；用户要求保色时不得擅自加入配方颜色，单色与禁用色不能和冲突墨色共存。纸感、套色均为视觉模拟，不声称有可印刷的独立色版。干净背景不额外加扭索纹；严格保留未授权更改的几何、对象、地平线、比例和透明通道。

【运行保护】
没有真实生图/改图工具就停止，给可复制的单一生产提示词，并明确未出图。具备工具才执行一次主生成和最多两次局部修复；读回产物检查内容保真、技法是否塌缩、跨物体同向纹、摩尔纹、配色及比例。未验证之项写 UNVERIFIED。
