# v1.3 母风格：一幅图只允许一种主导技法

## 永久不变的部分

- 尊重内容源的身份、数量、视角、结构和空间关系；无用户批准不得添加实体。
- 真正重绘时，画面的印痕语言必须属于对象的曲面、材质和透视，**不是在照片上覆盖统一图案**。
- 可读缩略图与微观可辨纹理并重；背景纹和纸张装饰永远从属于主体。
- 色板、背景、长宽比与技法独立；使用纸张油墨视觉描述不意味着真的制作了物理版或分色。

## 绝对不要再使用的旧规则

旧版本统一要求“所有明暗都由排线、交叉排线、点刻和留白组成”，会使 I01–I08 输出趋同；现在不再强制任何 T 技法必须有连续排线。

| 家族 | 主机制 | 缩图可识别特征 |
| --- | --- | --- |
| T01 刀刻 | 收尖长线、线距建调子 | 干净、秩序、精锐轮廓 |
| T02 蚀刻 | 活性绘线、交叉线簇 | 多层纹理、节奏丰富 |
| T03 干刻 | 划痕毛刺 | 局部柔绒黑色、断续笔痕 |
| T04 点刻 | 点的大小和数量 | 轮廓内疏密颗粒，少连续线 |
| T05 美柔汀 | 整片绒调底逐渐磨亮 | 完整的黑—灰—白明度域，不以线密为主 |

详细技术参数在 [techniques.md](techniques.md)，仅从该文件选择一个家庭。视觉配方 Ixx 只在其默认 T 家族下使用；覆盖 T 时跳过不兼容的配方节奏。

## 失败征象

1. 楼群、水面、船体、桥梁全部沦为同向横线；
2. T04 最终以平行线而非点群构形；T05 仍靠密集交叉排线建调子；
3. T03 的毛刺变成整图噪点；T01 的线条只是不带方向的网纹；
4. 同一照片换 T 标签、去除颜色后只剩密度差异；
5. 原图结构纹理（桥梁排布、楼体窗栅）被错认为雕刻主语，蔓延到其他物体。

这些问题应该进入实际 A/B 质检，不能被单元测试通过所取代。
