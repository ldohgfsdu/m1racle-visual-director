# 决策与约束解析 / Decision policy

## 优先级

1. 用户明确指定的内容、禁止项、保留项、配色、比例、透明背景和修改范围。
2. 编辑内容源的事实、身份、空间结构、现有配色及原比例。
3. 用户所选预设的适用刻线特征。
4. 新生成时可用的预设默认配色和背景建议。

用高优先级条件替换低优先级默认值，不把相冲突的句子都塞入提示词。用户要求改变某项时，该项不再受「保留原图」约束；其余项目继续锁定。例如换成红黑色后不再写「原配色不变」。同级明确要求无法共存时询问一次。

## 模式与图片角色

| 请求 | 操作 | 内容源 | 风格图 |
| --- | --- | --- | --- |
| 文字生成 | generate | 无 | 可选 |
| 借画风生成新主题 | generate | 无 | 可选，明确只学画风 |
| 照片或其他画风转绘 | redraw | 必须附上或明确等待上传 | 可选，独立标记 |
| 既有版画精修 | refine | 必须附上或明确等待上传 | 通常不需要 |
| 只给提示词 | 输出所需模式的模板 | 可等待后续附件 | 可等待后续附件 |

不把同一张图同时称为严格编辑源和仅风格参考。多图混用时逐图写出角色与可继承属性。CLI 的 `--role source` 无 `--image` 只表示待附图模板，不能声称已查看或处理原图。

## 内容与技法分开

先列出内容事实，再选择刻线节奏。自动选型评估形体适配、空间尺度、情绪与用户目标；无需虚构精确分数。并列时优先主体识别性和较少改动。无适配预设时使用 BASE，不能硬把动物、产品或标志塞进山城场景。

预设中的「海滨、肖像、港口」只是历史样图标签。不得因此增加建筑、人物、舟船、花枝、山体或光环，也不默认改变物体比例和姿态。不同预设的比较应保持同一内容事实。

## 配色解析

- 显式配色（含单色、黑白、禁用色）覆盖预设的所有默认色，连同名称里的色彩提示一起移除。
- 编辑没有换色要求时，沿用原图主辅色、纸底和大色块；精修无需重选配色。
- 新生成没有指定配色时才采用预设默认色；BASE 使用主题指定色，无指定时可用石墨与自然纸白。
- 只借用参考图的刻线时，不继承参考配色。指定第二张提供颜色时才从它提色。
- 真正的双色套印按色墨数量组织，不把纸底当作一层油墨。若要求透明背景，纸感只出现在需保留的印刷内容中，不填不透明旧纸底。

## 背景与保真

背景 auto：新生成仅在有用的背景留白中可选扭索纹；极简、静物或干净背景可省略。编辑沿用已有背景与装饰程度。
背景 none：去除或不使用装饰扭索底纹，不凭空删除主题必需的背景物体。
背景 guilloche：仅在可用留白增加扭索曲线，不覆盖主体、不移动物体来腾地方。

保真 strict（编辑默认）：锁定身份、数量、姿态、比例、位置、视点、轮廓、构图、识别性细节与原比例；只改变授权项。
保真 balanced：保持身份和主要空间关系，允许简化次要肌理。
保真 free：用户明确允许时可重构布局，仍遵守保留项和禁止项。

## 最终提示词

只留下当前模式的生产指令：主题 → 操作与已解析的保留项 → 刻线 → 唯一最终配色 → 背景 → 比例。不要把完整决策树发给图像模型。若有风格图，加角色隔离句；若无附图，别写「使用附图」。

中文隔离句：附图 [编号] 只提供指定的刻线和印刷质感；不得复用其物体、布局、透视、文字或故事。内容仅来自用户主题或标记的内容源。
English: Image [index] supplies only the specified engraving technique and print texture. Do not inherit its objects, layout, perspective, lettering or narrative. Derive content only from the theme or labeled content source.

## CLI 边界

关键词匹配先排除常见否定子句，英文按词边界匹配，不将机场 airport 中的 port 当海港。未知主题回落 BASE。分数只表示命中的文本提示，不是视觉置信度。

脚本无法完整理解自然语言、自动翻译变量、判断是否已经是版画，或推断任意图片角色。视觉助手应先理解请求，再设置 mode、palette、preserve、background 等参数。颜色变量不参与预设关键词选择。自动精修始终继承现有画风。

## v1.3 更正：技法是调子生成机制，非统一排线变化

五主技法 `T01–T05` 的主导明暗机制互相区分，旧母提示词中“一切由排线/交叉线/点刻共同形成”的总要求已经废止。用户指定技法优先于 I 配方；用户指定配色、禁止色优先于 P 色板及历史命名。配方名称不进入最终绘图指令。

决策顺序：选 T（refine 默认 INHERIT） → 选 I（无显式需要可省略；与 T 不兼容则略过 I 节奏） → 选 P（编辑默认继承）→ 背景 → 不变项 → 唯一生产提示词。不得因样图题材改变主体。

`--palette-id Pxx` 是用户显式要求的换色，在编辑模式下也优先于默认保色；`--palette '自由描述'` 更高。若主题写了明确禁色，主题优先于 `--palette-id`；若显式 `--palette` 与主题文字相互冲突，应由调用者在进入 CLI 前消除矛盾，不能仅依赖关键词推断。
