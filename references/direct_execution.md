# 明确选择后的直接执行

用户已经选择 I01/T01 等参数时，不再解决“选哪套风格”的问题。实际观察原图后锁定内容事实，读取当前配方、技法、对应参考和验收标准，组织一次生产指令，然后调用实际可用的图像工具。不创建视觉排序 JSON、不枚举其他候选、不重复读取相同资料。

```bash
python scripts/prompt_builder.py --image photo.jpg --style I01 --technique T01 --background none --fidelity strict --ratio 4:3 --json
```

CLI 不读取仅用于自动排序的 `--visual-analysis` 和 `--preferences` 文件，并在传入这些参数时明确提示未使用。用户的显式要求应直接通过 `--palette`、`--palette-id`、`--background`、`--fidelity`、`--ratio` 和主体要求传入。原色继承仍为编辑默认。精修默认 BASE/INHERIT，同样不做候选排序。

图像工具的尺寸参数与提示词长宽比应一致；工具不支持请求尺寸时如实报告。拿到输出后，优先使用现有看图能力检查，不为了惯例自行编写 PNG 解码器或逐张制作放大图。只有发现具体细节疑点且现有查看能力不足时，才额外取证。

质量门槛保持不变：内容检查、主技法与配方特征、颜色、比例、透明背景和装饰策略均需实际核验。尺寸及审查记录所需摘要尽量在一次文件检查中收集，不反复启动命令。缺证据保持 UNVERIFIED，存在问题保留 ISSUE；不能省略检查来制造提速。

默认对用户只返回图片、实际尺寸、验收状态与最多三条具体问题；详细记录仅按任务需要保存。不额外编写工作日志，不运行开发测试，不反复探测工具。是否修复仍遵守用户本轮授权；速度测试默认不修复、不生成备选。
